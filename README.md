This project includes a full neural network model with using RELU and Sigmoid activation functions. Visualizer shows how the neural network succeeds in prediction. Background colours are the predictions and datapoints are the true values.
---

## Tech Stack
* **Language:** Python 3.14
* **Libraries:** Numpy, Matplotlib

---

## Project Architecture

```text
├── main.py            # For running the visualizer
├── data.py            # Generates the datapoints for the neural network
├── requirements.txt   # Requirements
├── model.py           # Neural network model creation
└── README.md
```
---

## Quick Start

Follow these steps to set up and run the neural network visualizer.

### 1. Clone the Repository & Set Up Virtual Environment

### 2. Install build tools and requirements
```
pip install -r requirements.txt
```
### 3. Run main.py file
```
python main.py
```
